# React Blog UI

A responsive Blog UI built using React. This project dynamically displays blog posts using reusable components and JavaScript `.map()`.

## 🚀 Features

- Responsive blog layout for desktop, tablet, and mobile.
- Dynamic blog rendering using `.map()`.
- Reusable `BlogCard` component.
- Category-based filtering:
  - All
  - Full Stack Development
  - Data Science
  - Cyber Security
  - AI
- Clean and user-friendly interface.
- Blog data stored separately in `src/data/blogsData.js`.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Google Fonts – Open Sans

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/JayaJavaDev/React-Blog-UI.git
```

2. Navigate to the project folder:

```bash
cd React-Blog-UI
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 📦 Build for Production

```bash
npm run build
```

## 🎯 Project Objective

The objective of this project is to build a responsive Blog UI using React concepts such as components, props, reusable components, and dynamic rendering with `.map()`.
